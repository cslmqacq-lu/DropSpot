# 浮窗外观与关于页设计

## 目标

允许用户在设置中统一调整最小化浮窗相关界面的底色和不透明度，并在设置中显示软件版本与开发者声明。

## 设置交互

- “浮窗”页保留收藏显示数量。
- 增加颜色预览按钮，点击后打开 Windows 系统颜色选择器。
- 增加“背景不透明度”数字框，范围为 20% 至 100%，默认 70%。
- 增加“恢复默认外观”，恢复深色底色 `#080C12` 和 70% 不透明度。
- 点击“确定”后立即应用并保存；点击“取消”不修改当前外观。

## 应用范围

同一组颜色和不透明度统一应用到：

- 底部双文件夹浮窗。
- 向上展开的收藏快捷栏。
- 收藏路径与更新时间信息框。

文字颜色根据背景亮度自动切换深浅，避免用户选择浅色后文字不可读。透明蒙版保留色不可作为实际背景色，遇到该颜色时自动做最小偏移。

## 关于页

设置窗口新增“关于”页，显示：

- 软件名：DropSpot。
- 版本：动态读取 `Application.ProductVersion`。
- 开发者：cslm。

## 数据与资源

- `AppSettings` 保存背景 ARGB 值和不透明度百分比，旧配置缺少字段时使用当前默认外观。
- 外观变化只更新现有控件属性，不增加文件监听、目录扫描、计时器或后台线程。

## 验证

- 配置保存、备份恢复和旧配置默认值正常。
- 20%、70%、100% 不透明度均能正确应用。
- 深色与浅色背景下文字保持可读。
- 三类浮窗使用相同设置，恢复默认后回到 `#080C12 / 70%`。
- 关于页版本号与程序版本一致，开发者显示为 cslm。
- Release 构建和完整 smoke test 通过。
