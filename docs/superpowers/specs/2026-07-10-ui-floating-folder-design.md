# 活跃文件夹 UI 与浮动入口设计

## 目标

优化主窗口的信息层级，并在主窗口最小化后显示一个接近已确认预览效果的浮动文件夹入口。浮动入口用于一键打开最新活跃文件夹，同时维持现有低资源监听方式。

## 主窗口

主窗口继续保持现有紧凑尺寸、深色标题栏、最多 6 个活跃文件夹和每个文件夹最多展开 3 个文件。

- 最新文件夹使用绿色左侧指示线和略亮背景，其他卡片维持低对比度。
- 文件夹名称仍是卡片主信息。
- 路径显示最末两级目录，完整路径通过悬停提示提供。
- 相对时间优先显示，变化次数降为次级信息。
- 右侧 `+`/`-` 改为 30 像素展开箭头，扩大点击范围；展开状态使用向上箭头。
- 顶部三个图标按钮统一尺寸、描边、底色和悬停反馈。
- 状态区仅保留状态点与“监视中 · 盘符”或对应的暂停状态。

## 浮动入口外观

新增独立 `FloatingFolderForm`，视觉尽量贴近确认的浏览器预览：

- 整体大小为 `96×80`，无系统边框，不出现在任务栏。
- 背景使用近黑色，轻微透明，圆角约 12 像素。
- 使用系统大文件夹图标，水平居中。
- 文件夹名称位于图标下方，单行居中，超出宽度时省略。
- 右上角显示 8 像素状态点；监视中为绿色，暂停或无活动记录时为灰色。
- 边框为低对比度灰蓝色，并带轻量阴影感；WinForms 无原生阴影时优先保证圆角和边框，不引入高占用渲染。
- 悬停提示显示完整文件夹名称和完整路径。

## 最小化与交互

用户点击主窗口最小化按钮时：

1. 主窗口从任务栏隐藏。
2. 浮动入口显示在上次保存的位置并保持置顶。
3. 文件监听继续运行，不创建第二套监听器。

浮动入口交互：

- 单击：不执行操作，避免误触。
- 双击：用资源管理器打开当前最新活跃文件夹，浮动入口继续显示。
- 拖动：移动浮动入口；拖动结束后保存位置，不触发单击。
- 右键：显示“打开最新文件夹”“恢复主窗口”“暂停/继续监视”“退出”。
- 无活跃文件夹时：显示“暂无记录”，状态点为灰色；双击不执行操作，仍可从右键菜单恢复主窗口。

恢复主窗口只出现在右键菜单中，不绑定左键单击或双击。

## 位置持久化

`AppSettings` 增加浮动窗口坐标。首次使用时显示在主屏幕右下角、任务栏上方；以后使用保存坐标。

显示前检查坐标是否位于任一屏幕工作区。显示器被拔出、分辨率改变或坐标不可见时，将窗口校正到当前主屏幕右下角。拖动过程中不频繁写配置，只在拖动结束时保存一次。

## 数据流

主窗口仍是文件夹活动数据的唯一所有者。每次 UI 批次处理完成后，将最新的 `FolderActivity` 传给浮动入口更新名称、路径、提示和状态点。

浮动入口隐藏时只保存最新数据，不刷新绘制。显示后直接使用最近一次数据，不重新查询磁盘，也不扫描目录。

## 生命周期与错误处理

- 恢复主窗口时重新加入任务栏、恢复正常窗口状态并激活。
- 退出程序时先关闭浮动入口，再停止监听和释放图标资源。
- 最新文件夹已不存在时，双击不启动无效路径，浮动入口继续保留；用户可从右键菜单恢复主窗口。
- 浮动入口使用主窗口已缓存的共享文件夹图标，不重复获取系统图标。

## 验证

- 最小化后主窗口和任务栏按钮消失，浮动入口出现。
- 单击不触发任何动作。
- 双击只打开一次最新文件夹，不恢复主窗口。
- 只有右键菜单中的“恢复主窗口”能够恢复主窗口。
- 拖动不触发打开动作，位置在重启后保持。
- 显示器工作区变化后浮动入口仍可见。
- 无活动记录、暂停监视和继续监视状态正确。
- 连续文件变化只更新文字和状态，不新增控件或监听器。
- 主窗口最新卡片高亮、路径缩写、箭头展开和现有打开功能正常。
- Release 构建、烟雾测试、GDI 压力测试和 Windows 实机截图检查全部通过。

## 边界

本轮不增加历史数据库、系统托盘图标、持续动画、声音通知或第二套监听机制。关闭主窗口仍表示退出；只有最小化动作会切换到浮动入口。
