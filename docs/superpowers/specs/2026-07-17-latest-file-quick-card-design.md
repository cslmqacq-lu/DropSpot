# DropSpot 最近文件快捷卡设计

日期：2026-07-17
状态：已确认交互方向，待实现计划
适用版本：DropSpot 1.0.3 之后

## 目标

在最小化浮窗的“最新活跃文件夹”上增加最近文件快捷卡，让用户保存图片、文档或其他工作文件后，无需打开资源管理器即可：

- 直接使用默认程序打开最近文件。
- 将真实文件拖到微信、邮件、浏览器上传框或资源管理器。
- 继续通过双击快速打开文件所在文件夹。

该功能必须沿用现有 USN Journal 数据，不新增目录扫描、文件内容读取或额外文件系统监听器。

## 已确认交互

### 收起状态

- 主浮窗尺寸和左右两段结构保持不变。
- 左侧仍表示最新活跃文件夹，右侧仍表示收藏夹。
- 左侧箭头表示最近文件卡可以向上展开。

### 单击与双击

- 单击左侧最新活跃文件夹后，等待 Windows 系统双击时间，再展开或收起最近文件卡。
- 双击左侧最新活跃文件夹时，取消待执行的单击动作，直接打开文件夹。
- 该规则与现有右侧收藏夹的单击/双击计时方式保持一致。

### 展开状态

- 最近文件卡作为独立浮窗，固定显示在左侧最新活跃文件夹正上方。
- 主浮窗本身不移动，避免第一次点击后改变第二次点击的位置。
- 只显示最近保存的 1 个正常且仍存在的文件。
- 文件卡显示系统文件类型图标和经过省略处理的文件名。
- 新文件到达时，展开状态保持不变，只在原位置换图标和文件名。

### 文件操作

- 单击文件图标、文件名或文件卡主体：使用 Windows 默认程序打开文件。
- 按住文件图标或文件名并移动超过系统拖拽阈值：开始真实文件拖拽。
- 拖拽使用 `DataFormats.FileDrop`，效果默认为 `DragDropEffects.Copy`。
- 右键文件卡提供：打开文件、打开所在文件夹、复制文件路径。
- 再次单击左侧文件夹、双击打开文件夹、恢复主窗口或隐藏浮窗时，收起最近文件卡。

## 最近文件选择规则

数据直接来自最新活跃 `FolderActivity.Files`，按记录时间从新到旧选择第一条满足条件的记录。

候选文件必须：

- 路径非空。
- 当前仍然存在。
- 不是明显的临时、下载中或 Office 锁文件。

第一版过滤以下名称或扩展名：

- 文件名以 `~$` 开头。
- 扩展名为 `.tmp`、`.temp`、`.part`、`.crdownload`、`.download`。
- 文件名以 `.tmp` 或 `.temp` 结尾。

若最新记录不符合条件，继续检查内存中已有的下一条记录。最多检查 `FolderActivity` 当前保留的 25 条记录，不遍历目录。

文件存在性检查不得阻塞 UI 线程。检查完成前可以保持旧卡内容；没有可用文件时不显示快捷卡。

## 组件设计

### LatestFileSelector

职责：从已有 `ChangeRecord` 集合中选择最近可用文件。

输入：

- `IReadOnlyList<ChangeRecord>`。

输出：

- 一个可用 `ChangeRecord`，或 `null`。

该组件封装临时文件过滤和异步存在性检查，不依赖 WinForms 控件，便于单元和 smoke test 覆盖。

### LatestFileQuickForm

职责：显示单个最近文件卡并处理文件交互。

包含：

- 与收藏快捷项一致的大文件图标区域。
- 单行文件名。
- 透明、圆角、置顶且不进入任务栏的背景层。
- 打开、右键菜单、拖拽开始和自动收起逻辑。

位置：

- 以 `_activeSegment` 的屏幕矩形为锚点。
- 卡片底部与左侧文件夹顶部保持约 6px 间距。
- 横向与左侧文件夹居中对齐。
- 屏幕空间不足时直接裁剪，不改变主浮窗位置；与收藏向上展开规则一致。

### FloatingFolderForm

新增职责：

- 保存当前最近可用文件。
- 管理左侧单击计时器。
- 区分单击展开与双击打开文件夹。
- 更新、定位、显示和关闭 `LatestFileQuickForm`。
- 在拖动主浮窗时同步最近文件卡位置。

### MainForm

新增职责：

- 将最新活跃文件夹和其最近文件记录一起传给浮窗。
- 提供异步打开文件、打开所在文件夹和复制路径回调。
- 最小化状态下继续维护数据，但不恢复主窗口卡片渲染。

## 数据流

1. USN Journal 产生关闭后的文件变更记录。
2. `PendingRecordBuffer` 按现有 1 秒周期合并记录。
3. `FolderActivity` 更新最近文件列表。
4. `LatestFileSelector` 从最新活跃文件夹的内存记录中选择最近可用文件。
5. `FloatingFolderForm.UpdateLatest` 更新左侧文件夹和最近文件状态。
6. 最近文件卡已展开时，`LatestFileQuickForm` 在原位更新显示。
7. 用户单击打开或开始 `FileDrop` 拖拽，接收方应用读取真实文件。

## 性能约束

- 不创建新的文件系统监视器。
- 不扫描目录，不枚举目录文件。
- 不读取文件内容，不生成图片缩略图，不计算哈希。
- 文件类型图标继续复用 `ShellIconProvider` 按扩展名缓存。
- 最近文件存在性检查仅在最新记录变化或用户展开时运行，并放到后台线程。
- 单击计时器和鼠标位置检查只在相应浮层可见或等待交互时运行。
- 最近文件卡关闭后不得保留高频计时器。

## 异常处理

- 文件在选择后被移动或删除：打开或拖拽前再次确认存在；失效时关闭卡片并刷新下一条可用记录。
- 没有默认打开程序：保留浮窗并在状态区域显示失败原因。
- 目标应用不接受拖拽：拖拽结束后保持文件卡，不改变文件。
- 跨权限级别拖拽被 Windows 阻止：不提升 DropSpot 权限，保持当前低权限运行模型。
- 新记录到达期间正在拖拽：当前拖拽继续使用开始拖拽时的路径，拖拽结束后再刷新为最新文件。
- 文件名过长：单行省略，悬停提示显示完整文件名和完整路径。

## 既有浮层可靠性修复

实现本功能时一并修复收藏信息框偶尔不消失的问题：

- 不再只依赖透明控件的 `MouseLeave`。
- 信息框显示期间使用低频鼠标位置检查。
- 鼠标离开对应收藏项后立即隐藏信息框。
- 检查只在信息框可见时运行，隐藏后停止。

## 测试标准

### 选择逻辑

- 普通文件能被选中。
- `~$`、`.tmp`、`.part`、`.crdownload` 等记录被跳过。
- 最新文件已删除时选择下一条仍存在的记录。
- 所有记录失效时返回 `null`。

### 单击与双击

- 单击只展开或收起一次。
- 双击取消单击动作并只打开一次文件夹。
- 连续快速点击不会创建多个最近文件窗体或多个资源管理器窗口。

### 文件操作

- 单击文件卡调用默认程序打开正确路径。
- 拖动不足系统阈值仍视为点击。
- 超过阈值后产生包含唯一文件路径的 `FileDrop`。
- 右键菜单的打开、打开所在文件夹、复制路径均作用于当前显示文件。

### 动态更新

- 文件卡展开时写入新文件，卡片原位更新且不闪烁。
- 主浮窗移动时，文件卡保持锚定在左侧文件夹上方。
- 恢复主窗口、隐藏浮窗或退出程序后，没有残留顶层窗口。
- 收藏信息框在鼠标离开对应收藏项后可靠消失。

### 回归与性能

- 原有右侧收藏夹展开、双击打开、右键菜单不受影响。
- 最小化时仍停止主窗口卡片渲染。
- Release build、现有 smoke test 和新增选择/交互 smoke test 全部通过。
- 静置 CPU 维持接近 0%，不存在持续增长的线程、句柄或私有内存。

## 非目标

- 第一版不显示多个最近文件。
- 不生成图片或文档缩略图。
- 不提供文件分享 API 或内置发送功能。
- 不复制、移动或上传文件；DropSpot 只提供打开与标准 Windows 文件拖拽。
- 不新增用户可配置的最近文件数量。
