# DropSpot

DropSpot 是一个低占用的 Windows 小工具，用来监视指定硬盘的文件新建、写入、更新和重命名事件，并优先按“最近活跃文件夹”展示，方便快速定位文件被写入到哪里。删除事件默认完全忽略。

当前版本：`1.0.0`

## 运行

新版发布目录：

```powershell
G:\AI开发相关\DropSpot\bin\Release\net8.0-windows\DropSpot.exe
```

也可以在项目目录运行：

```powershell
dotnet run
```

## 使用方式

1. 主窗口默认是深色小窗口，只显示最近活跃文件夹。
2. 点击“设置”，在二级窗口里勾选要监视的硬盘。
3. 在设置窗口的“排除文件夹”里添加不关心的噪音目录。
4. 下次启动时，如果已经勾选硬盘，会自动开始监视。
5. 文件夹会按最近更新时间自动排序。
6. 活跃文件夹最多保留 6 个，新事件会覆盖旧的文件夹。
7. 双击文件夹卡片可以打开这个文件夹。
8. 点击卡片右侧的 `+` 可以展开文件。
9. 展开后只显示最新 3 个文件，单击文件可用系统默认工具打开。
10. 右键文件夹卡片可以打开、加入排除或复制路径。
11. 最小化主窗口后会显示一个 `208×86` 的双文件夹浮动入口：左侧是最新活跃文件夹，右侧是最近更新的收藏。
12. 双击左侧打开最新活跃文件夹；单击右侧向上展开收藏第 2 至第 5 位，双击右侧打开收藏第 1 位。
13. 悬停右侧或展开后的收藏，会显示跟随当前文件夹位置的信息框，包含完整路径和最后更新时间。
14. 右键左侧可复制最新文件夹路径或加入收藏；右键任意收藏可复制对应路径。
15. 恢复主窗口只能从右键菜单选择；浮动入口拖动后会记住位置。
16. 主窗口可在“活跃 / 收藏”之间切换，右键活跃文件夹即可加入收藏。
17. 收藏文件夹自身或任意子目录更新后，会自动移动到收藏页和浮动快捷栏的最前面。
18. 收藏页底部的 `+` 可手动输入或浏览选择任意已有目录，并立即加入收藏。
19. 设置窗口的“浮窗”页可设置收藏显示总数，范围为 1 至 14；最新收藏固定在底部，其余按更新时间向上展开。
20. “浮窗”页还可统一修改浮窗、收藏展开栏和信息框的背景色与背景不透明度；文件夹图标和文字始终保持完全不透明。“关于”页显示当前版本和开发者 `cslm`。

## 当前实现

- 底层监听已切换为 NTFS/ReFS 的 USN Journal。
- 每个卷只开一个 USN 增量读取循环，不再递归挂 `FileSystemWatcher`。
- 只读取需要的 USN 原因，并在文件关闭后汇总，降低连续保存产生的事件风暴。
- 不扫描文件内容，不计算 hash，不做全盘文件内容读取。
- 支持 USN V2/V3 文件编号，并缓存父目录路径，减少重复调用系统路径解析。
- 后台事件按文件路径合并并设置容量上限，UI 每秒最多处理固定数量。
- 最多 6 张文件夹卡片会被复用，不再每秒清空重建控件。
- 最小化后只维护事件数据和浮窗，暂停主窗口卡片渲染；恢复时一次性同步当前页面。
- 最新文件夹卡片使用绿色指示线，并优先显示最近两级路径。
- 最小化后使用一个 `208×86` 双区浮动入口，并按设置向上展开收藏；显示总数可在 1 至 14 之间调整，不新增监听器或目录扫描。
- 浮动入口、收藏快捷栏和信息面板统一使用 70% 不透明度，不启用模糊；信息面板固定显示在对应收藏右侧。
- 使用原生圆角裁剪并取消系统投影和常驻外框，避免边缘白色毛边。
- 收藏排序变化时复用已有快捷项，只更新内容和位置，避免反复创建控件。
- 收藏夹保存在现有设置中，活动时间最多每 30 秒批量保存一次。
- 收藏页使用独立轻量行控件，不占用活跃列表的 6 个位置。
- 主逻辑是“监视硬盘 + 排除文件夹”，更适合发现写入位置。
- 设置会原子保存到 `%AppData%\DropSpot\settings.json`，并保留一个 `.bak` 备份；首次启动会自动复制旧版 `%AppData%\DiskWriteWatcher` 设置。

## 当前边界

- USN Journal 读取可能需要管理员权限；如果某个盘无法启动监听，请用管理员身份运行。
- FAT32、exFAT 等不支持 USN Journal 的文件系统无法用此底层监听。
- 软件只读取已有 USN Journal，不会自动创建或修改磁盘日志配置。
- 这版从启动后的当前 USN 位置开始监视，不回放历史事件。

## 验证

项目内置了自动 smoke test：

```powershell
dotnet run -- --smoke-test
```

发布版也可以验证：

```powershell
$p = Start-Process -FilePath "G:\AI开发相关\DropSpot\bin\Release\net8.0-windows\DropSpot.exe" -ArgumentList "--smoke-test" -Wait -PassThru
$p.ExitCode
```

退出码 `0` 表示新建、独立更新、删除忽略、排除目录、停止重启、有界缓冲、卡片资源和配置备份恢复测试全部通过。
