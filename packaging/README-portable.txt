开发者：cslm

使用方法
1. 双击 DropSpot.exe 启动，无需安装 .NET 运行时。界面就是桌面上的悬浮舱，没有主窗口。
2. 首次使用点悬浮舱里的“授权后台监视”，确认一次管理员授权；之后开机和启动都不再弹窗。
3. 鼠标移到悬浮舱上展开：最新文件、活跃文件夹、收藏夹都在一个面板里；移开自动收起。
4. 把文件或文件夹拖到悬浮舱上即可收藏；拖到屏幕左右边缘会贴边隐藏成细条。
5. 底栏 ⚙ 打开设置：监视磁盘、过滤规则、快捷键、背景不透明度、随 Windows 启动。
6. 托盘图标左键展开面板，右键可暂停监视、查看活动记录和诊断。

用户设置
设置与收藏保存在：%AppData%\DropSpot
移动或替换便携版程序不会删除这些数据。

注意
- USN Journal 读取需要管理员权限，由已授权的后台监视进程完成；界面本身以普通权限运行，拖放不受影响。
- FAT32、exFAT 不支持本软件使用的 USN 监视方式。
- 本程序未进行数字签名，Windows 首次运行时可能显示 SmartScreen 提示。
