# 文件夹收藏夹设计

## 目标

在现有“活跃文件夹”之外增加一个持久化的文件夹快捷方式收藏页。活跃页回答“刚刚哪里发生了变化”，收藏页回答“哪些目录值得长期快速访问”。收藏功能不能增加目录扫描，也不能明显增加配置写入频率。

## 主窗口结构

顶部工具栏保持不变，在工具栏与内容区域之间增加紧凑的“活跃 / 收藏”标签切换。

- “活跃”继续显示最近 6 个活跃文件夹和可展开的最新 3 个文件。
- “收藏”显示所有收藏文件夹，不受活跃文件夹数量限制。
- 启动时默认显示“活跃”。
- 切换标签不停止监听，不清空任何数据。

收藏项是轻量文件夹快捷方式，不提供文件展开：显示系统文件夹图标、文件夹名称、最近两级路径和最近活动时间。双击收藏项直接用资源管理器打开文件夹。

## 加入与移除收藏

活跃文件夹右键菜单增加“加入收藏”。同一路径使用不区分大小写的规范化路径去重；已收藏时菜单项显示“已收藏”并禁用。

收藏项右键菜单提供：

- 打开文件夹。
- 移除收藏。
- 复制路径。

移除收藏只删除应用内快捷方式，不操作真实文件夹。

## 活动排序

收藏项按 `LastActivity` 降序排列。新加入收藏时，使用对应活跃文件夹的最近活动时间；没有活动时间时使用收藏时间。

收到文件事件后，在更新活跃列表的同时检查收藏路径：

- 文件所在文件夹与收藏路径相同，更新该收藏的活动时间。
- 文件所在文件夹位于收藏路径的任意子目录中，也更新该收藏的活动时间。
- 一个事件可以同时更新父级和更深层的多个收藏项。

更新后只重排内存数据。收藏标签当前可见时更新收藏列表；不可见时不创建或更新收藏控件，切换到收藏标签后按最新顺序渲染。

收藏路径不再处于监视范围、被加入排除或所在磁盘不可用时，收藏记录仍保留为快捷方式，但不会收到新的活动时间。

## 数据模型与持久化

`AppSettings` 增加 `FavoriteFolders`，每项包含规范化路径、收藏时间和最近活动时间。

- 加入或移除收藏后立即保存设置。
- 活动时间变化只标记收藏数据为脏数据。
- 使用 30 秒单次定时器批量保存脏数据，不为每个文件事件写配置。
- 正常退出时保存尚未落盘的收藏活动时间。
- 继续使用现有临时文件、原子替换和 `.bak` 备份机制。

## 收藏列表资源控制

收藏数量不设置业务上限。收藏页使用轻量、固定高度的行控件，不使用可展开的 `FolderCard`。控件按路径复用；新增时创建、移除时立即释放、排序时只调整顺序。

收藏标签不可见时不执行界面重排。系统文件夹图标继续使用共享缓存。

## 不存在与异常状态

收藏文件夹不存在或磁盘未连接时，名称和路径使用弱化颜色，并显示“不可用”。双击不启动资源管理器；右键仍可复制路径或移除收藏。路径重新可用后，在下次显示收藏页时恢复正常状态。

配置中的重复、空白或无效路径在加载时忽略，不影响其他收藏项。

## 验证

- 活跃文件夹可通过右键加入收藏，重复路径不会重复添加。
- 收藏页和活跃页切换不影响监听。
- 收藏目录直属文件更新后移动到首位。
- 收藏目录任意层级子目录更新后也移动到首位。
- 同一事件可以更新多个嵌套收藏路径。
- 不在监视范围和被排除的收藏仍能保留与打开。
- 收藏活动事件不会逐条写配置，30 秒后批量保存；退出时保存脏数据。
- 不存在的收藏项显示不可用且可移除。
- 收藏控件重复排序时 GDI 对象和控件数量不持续增长。
- Release 构建、烟雾测试和 Windows 实机标签切换检查通过。

## 边界

本轮不增加收藏分组、标签、搜索、云同步、手动拖动排序或 Windows `.lnk` 文件。收藏是应用内部保存的文件夹路径快捷方式。
