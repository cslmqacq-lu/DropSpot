# DropSpot PNG 浮窗背景设计

## 目标

使用用户提供的三张 PNG 完整定义主浮窗、收藏展开项和收藏信息框的背景，消除系统圆角、Region 裁剪和代码描边造成的边缘残影。图标与文字保持完全不透明。

## 方案

每个浮动前景窗口配套一个无激活、鼠标穿透的逐像素 Alpha 背景窗口。主框使用 `212×90` 图片，单个收藏框使用 `108×90` 图片，提示框使用 `196×90` 图片。前景窗口使用色键透明，只绘制图标、文字和状态；主框分隔线、圆角、描边、颜色和透明度全部来自 PNG。收藏展开栏按项目位置把收藏框 PNG 合成到透明画布，项目间隙保持透明。

背景窗口始终位于对应前景窗口的正后方，随前景同步显示、隐藏、移动和销毁。右侧信息框仍固定在收藏项右侧 12 像素。颜色和透明度设置及持久化字段已移除，图片 Alpha 是唯一的背景外观来源。主框图片层参与鼠标命中，使圆角框内部的空白区域同样支持拖动和右键菜单。

## 验证

- 构建与现有 smoke test 均通过。
- 主浮窗四角没有矩形底色或白边。
- 收藏展开后，项目间隙透明且位置稳定。
- 信息框圆角外无额外右侧色块。
- 图标与文字不受背景透明度影响。
