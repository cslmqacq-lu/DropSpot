# DropSpot

DropSpot 是一个低占用的 Windows 小工具，用来监视指定硬盘的文件新建、写入、更新和重命名事件，并优先按“最近活跃文件夹”展示，方便快速定位文件被写入到哪里。删除事件默认完全忽略。

当前版本：`1.0.7`

## 运行

新版发布目录：

```powershell
G:\AI开发相关\DropSpot\bin\Release\net8.0-windows\DropSpot.exe
```

也可以在项目目录运行：

```powershell
dotnet run
```

## 使用方式

1. 主窗口默认是深色小窗口，只显示最近活跃文件夹。
2. 点击“设置”，在二级窗口里勾选要监视的硬盘。
3. 在设置窗口的“排除文件夹”里添加不关心的噪音目录。
4. 下次启动时，如果已经勾选硬盘，会自动开始监视。
5. 文件夹会按最近更新时间自动排序。
6. 主窗口显示最近 6 个活跃文件夹；后台仅保留最近 50 个文件夹的轻量历史。
7. 双击文件夹卡片可以打开这个文件夹。
8. 点击卡片右侧的 `+` 可以展开文件。
9. 展开后只显示最新 3 个文件，单击文件可用系统默认工具打开。
10. 右键文件夹卡片可以打开、加入排除或复制路径。
11. 点击工具栏的悬浮按钮会打开 `208×86` 双文件夹浮动入口；系统最小化会进入任务栏，恢复后回到最小化前的悬浮状态。
12. 单击左侧可向上展开最近一个正常文件；单击文件用默认程序打开，拖动文件卡可发送或上传真实文件。
13. 双击左侧仍直接打开最新活跃文件夹；单击右侧向上展开更多收藏，双击右侧打开收藏第 1 位。
14. 悬停右侧或展开后的收藏，会显示跟随当前文件夹位置的信息框，包含完整路径和最后更新时间。
15. 右键左侧可复制最新文件夹路径或加入收藏；右键任意收藏可复制对应路径。
16. 浮窗右键可恢复主窗口或最小化到任务栏；浮动入口拖动后会记住位置。
17. 主窗口可在“活跃 / 收藏”之间切换，右键活跃文件夹即可加入收藏。
18. 收藏文件夹自身或任意子目录更新后，会自动移动到收藏页和浮动快捷栏的最前面。
19. 收藏页底部的 `+` 可手动输入或浏览选择任意已有目录，并立即加入收藏。
20. 设置窗口的“浮窗”页可设置收藏显示总数，范围为 1 至 14；最新收藏固定在底部，其余按更新时间向上展开。
21. 钉住文件夹有新活动时显示静态绿色提示点，打开后自动清除。
22. 系统托盘可恢复主窗口、打开悬浮窗、暂停或继续监视、查看最近 50 个活动文件夹、查看诊断和退出。
23. “设置 → 快捷键”可分别配置“打开最新文件夹”和“复制最新文件夹地址”；默认是 `Ctrl+Alt+F` 与 `Ctrl+Alt+D`，支持勾选 `Ctrl / Alt / Shift` 并选择 `A-Z` 字母。
24. 设置窗口的“诊断”页可以查看每个磁盘的实时状态、最近事件和错误日志。
25. “常规”页可启用随 Windows 启动；开机启动时自动开始监视并进入浮窗。
26. 以管理员身份运行时，开机启动会注册为“以最高权限运行”的计划任务（任务名 `DropSpot`）；普通身份运行时退回注册表启动项，并在权限不足时显示“以管理员重启”提示条（托盘菜单同样提供）。
27. 双击活跃文件夹、快捷键或浮窗打开最新文件夹时，默认在资源管理器中选中最新文件，可在“常规”页关闭。
28. 展开后的文件行支持拖出真实文件，右键可在文件夹中显示、打开方式、复制文件 / 路径 / 文件名。
29. “排除文件夹”支持完整路径，也支持名称或通配符（如 `node_modules`、`*_temp_*`），任意层级匹配即排除；默认开启“过滤常见噪音目录”（.git、node_modules、浏览器缓存等）。
30. 把文件或文件夹从资源管理器拖到浮窗、主窗口或“收藏文件”小窗口上即可收藏：文件夹直接加入收藏；文件会归到路径最深的已收藏上级文件夹下（没有的话自动收藏它所在的文件夹），只记录位置，不复制文件。以管理员身份运行时同样可以拖入。
31. 有收藏文件时，浮窗旁会常驻一个“收藏文件”小窗口：单击打开，按住可拖出真实文件，右键可在文件夹中显示、复制或取消收藏。
32. 主窗口“收藏”页会在每个收藏文件夹下列出带 ★ 的收藏文件；“活跃”页展开的文件行右键可“收藏此文件”，已收藏的文件名前显示 ★。

## 当前实现

- 底层监听已切换为 NTFS/ReFS 的 USN Journal。
- 每个卷只开一个 USN 增量读取循环，不再递归挂 `FileSystemWatcher`。
- 每个卷独立维护健康状态；磁盘尚未就绪、移动盘重连或 USN Journal 重建后会自动重新打开卷并继续监视。
- 只读取需要的 USN 原因，并在文件关闭后汇总，降低连续保存产生的事件风暴。
- 不扫描文件内容，不计算 hash，不做全盘文件内容读取。
- 支持 USN V2/V3 文件编号，并缓存父目录路径，减少重复调用系统路径解析。
- 后台事件按文件路径合并并设置容量上限，UI 每秒最多处理固定数量。
- 最多 6 张文件夹卡片会被复用，不再每秒清空重建控件。
- 悬浮模式或任务栏最小化时只维护事件数据和浮窗，暂停主窗口卡片渲染；恢复时一次性同步当前页面。
- 最近文件快捷卡只检查最新活跃文件夹内存中已有的 25 条记录，不扫描目录；临时文件和已删除记录会被跳过。
- 快捷卡只显示最近一个可用文件，支持默认程序打开、右键操作和标准 Windows `FileDrop` 拖拽。
- 最新文件夹卡片使用绿色指示线，并优先显示最近两级路径。
- 最小化后使用一个 `208×86` 双区浮动入口，并按设置向上展开收藏；显示总数可在 1 至 14 之间调整，不新增监听器或目录扫描。
- 浮动入口、收藏快捷栏和信息面板使用用户提供的 PNG 外框；不再对图片外框应用运行时透明度和改色。
- 收藏排序变化时复用已有快捷项，只更新内容和位置，避免反复创建控件。
- 收藏夹保存在现有设置中，活动时间最多每 30 秒批量保存一次。
- 最近 50 个活跃文件夹和每个文件夹最多 3 条文件记录保存在现有设置中，并按 30 秒批量保存。
- 日志按大小滚动保存在 `%AppData%\DropSpot\logs`，最多保留当前文件和 4 个归档。
- 托盘和全局快捷键使用 Windows 原生消息，不增加目录扫描或高频轮询。
- 收藏页使用独立轻量行控件，不占用活跃列表的 6 个位置。
- 主逻辑是“监视硬盘 + 排除文件夹”，更适合发现写入位置。
- 设置会原子保存到 `%AppData%\DropSpot\settings.json`，并保留一个 `.bak` 备份；首次启动会自动复制旧版 `%AppData%\DiskWriteWatcher` 设置。
- 正常运行使用单实例；重复启动只会恢复已有主窗口，不会重复监听硬盘或并发写设置。

## 当前边界

- USN Journal 读取可能需要管理员权限；无权限时对应磁盘会显示错误并自动低频重试，可在诊断页查看原因。
- FAT32、exFAT 等不支持 USN Journal 的文件系统无法用此底层监听。
- 软件只读取已有 USN Journal，不会自动创建或修改磁盘日志配置。
- 这版从启动后的当前 USN 位置开始监视，不回放历史事件。

## 验证

项目内置了自动 smoke test：

```powershell
dotnet run -- --smoke-test
```

发布版也可以验证：

```powershell
$p = Start-Process -FilePath "G:\AI开发相关\DropSpot\bin\Release\net8.0-windows\DropSpot.exe" -ArgumentList "--smoke-test" -Wait -PassThru
$p.ExitCode
```

退出码 `0` 表示新建、独立更新、删除忽略、排除目录、停止重启、重连状态、有限历史、钉住未读、卡片资源和配置备份恢复测试全部通过。
