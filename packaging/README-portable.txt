使用方法
1. 双击 DropSpot.exe 启动，无需安装 .NET 运行时。
2. 在“设置”中选择需要监视的 NTFS/ReFS 硬盘。
3. 点击主窗口的悬浮按钮打开浮窗；系统最小化会进入任务栏。
4. 托盘菜单可恢复主窗口、打开浮窗、暂停监视和查看诊断。
5. 可在“设置 → 常规”中启用随 Windows 启动；登录后会自动进入浮窗。
6. 可在“设置 → 快捷键”中配置打开最新文件夹和复制最新文件夹地址。

用户设置
设置与收藏保存在：%AppData%\DropSpot
移动或替换便携版程序不会删除这些数据。

注意
- USN Journal 读取可能需要管理员权限。
- FAT32、exFAT 不支持本软件使用的 USN 监视方式。
- 本程序未进行数字签名，Windows 首次运行时可能显示 SmartScreen 提示。
