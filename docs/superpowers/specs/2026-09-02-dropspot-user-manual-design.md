# DropSpot 1.0.7 中文使用说明长图设计

## 目标

制作一张无需配套文档即可完成首次上手的竖版中文说明长图。画面同时承担“认识界面”“完成设置”“掌握日常操作”三件事，并使用 DropSpot 1.0.7 的真实截图作为主要证据。

## 版式

- 成品尺寸：1800 x 3800 px，PNG。
- 视觉：深色中性底，绿色表示监视状态，黄色表示文件夹动作；不使用渐变和装饰性光斑。
- 信息顺序：产品定位 -> 首次设置 -> 活跃文件夹 -> 收藏与钉住 -> 悬浮窗 -> 快捷键与托盘 -> 速查。
- 截图不拉伸；用编号、细线和独立文字区解释，标注不得遮挡按钮与文件名。

## 必须说明的行为

1. 在“设置 -> 监视硬盘”选择要监视的 NTFS/ReFS 磁盘。
2. 在“设置 -> 排除文件夹”过滤缓存、临时目录等噪音位置。
3. 新建文件和重新保存均可记录，删除事件不进入活跃列表。
4. 活跃文件夹按最近更新时间排序，最多显示 6 个；双击卡片打开目录。
5. 点击卡片右侧展开按钮查看最新 3 个文件，单击文件用默认程序打开。
6. 活跃文件夹可加入收藏或钉到浮窗；收藏在自身或子目录更新后排到最前。
7. 悬浮窗左侧为最新活跃文件夹，右侧为收藏第 1 位；收藏列表向上展开。
8. 默认快捷键：Ctrl+Alt+F 打开最新文件夹，Ctrl+Alt+D 复制最新文件夹地址。
9. 托盘菜单可恢复主窗口、打开悬浮窗、暂停/继续监视、查看历史与诊断。
10. “随 Windows 启动”会在登录后自动开始监视并进入浮窗。
